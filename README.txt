NOTHANDO CYNTHIA ABBA ARMOOH - COMMUNICATIONS PORTFOLIO

GETTING STARTED
Open index.html in any modern browser. No installation, build command,
configuration, web server, external font service or backend is required.

GITHUB PAGES DEPLOYMENT
1. Add all project files to a GitHub repository, preserving the folder structure.
2. Push the files to your chosen branch.
3. In the repository, open Settings > Pages.
4. Choose "Deploy from a branch", select your branch and "/ (root)", then Save.
5. Open the published URL shown by GitHub once deployment completes.

The site supports both account sites and repository/project sites. All internal
links and asset paths are relative. The .nojekyll file keeps publishing static.

CONTENT AND MAINTENANCE
- The six HTML pages contain their own semantic content, navigation and footer.
  Update shared navigation/footer content consistently across all six pages.
- css/style.css contains the shared mobile-first design.
- js/script.js provides mobile navigation, the copyright year, and portfolio
  search/category filtering. The site remains readable without JavaScript.
- portfolio.html contains all six articles. data-categories uses pipe-separated
  category names; data-topics supplies additional searchable topic keywords.
  Keep the visible categories and the data attributes consistent when editing.
- Article links point directly to the original University of Limpopo pages.
  The science outreach article explicitly acknowledges its co-author.
- Professional content is based on the CV provided by the owner. Review dates,
  qualifications and the "Present" role when making future updates.
- documents/nothando-cv.pdf is the two-page, privacy-safe download.
  documents/nothando-cv.txt is its accessible, editable text companion.
  Keep both versions consistent when replacing the public CV.
- Never upload the original private CV, phone numbers, private addresses,
  identification details or references' contact information.
- Supplied portraits were re-encoded without source metadata; do the same for
  replacement photographs and check that they contain no GPS information.
- Contact links use the owner's public email address and LinkedIn profile.
  There is no contact form, tracking, analytics or third-party script.

PRE-PUBLISH CHECKS
Open each page and confirm navigation, images, CV downloads and article links.
Check mobile navigation with Enter/Space and Escape. Search for a title, a topic
and a description; apply a category while a search is active. Check an unmatched
search and confirm the exact empty-state message. Review layouts at 375, 768,
1024 and 1440 pixels. Recheck the public PDF for private information.
